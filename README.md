# Akaik

Личный сайт: анимированный лес со сменой сезонов и времени суток, дождь, снег, гроза, lo-fi музыка.

## Структура
- `index.html` — разметка
- `css/style.css` — стили
- `js/state.js` — настройки, хелперы, сезон и время суток
- `js/scene.js` — canvas-фон (лес, небо, осадки, молнии, цитаты)
- `js/ui.js` — панель настроек и наклон ника
- `js/music.js` — lo-fi треки (Web Audio) и звук кнопок
- `assets/avatar.jpg` — аватарка

## Запуск
Открой `index.html` в браузере или выложи папку на GitHub Pages / любой статический хостинг.
Скрипты подключаются по порядку: state, scene, ui, music.
